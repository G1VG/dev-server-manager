How the dashboard works

Browser → Flask → Linux

The browser calls a localhost-only Flask API. The API validates requests, runs whitelisted Linux commands, and delegates cleanup and backup work to the existing Bash scripts; cron can schedule the monitoring script independently.

Dashboard features → Linux commands

Production mode
Dashboard feature What it does Linux commands / files
Overview & health Load, memory, uptime, sessions, disk, and alert telemetry /proc/loadavg, /proc/meminfo, uptime, who, df, getent
Developer accounts List, create, lock, unlock, and remove developer users getent, lastlog, useradd, chpasswd, chage, usermod, userdel, id
Shared repositories Inspect and initialize shared bare Git repositories git init --bare, du, stat, chgrp, chmod
Storage (LVM) Inspect physical/volume groups and logical volumes; extend an LV pvs, vgs, lvs, lvextend -r, statvfs
Automation & cleanup Read scheduled jobs and preview or run disk cleanup /etc/cron.d/devserver, bash scripts/cleanup.sh --dry-run, bash scripts/cleanup.sh
Backups Create verified archives and list existing backups bash scripts/backup.sh, tar, du, /srv/backups
System logs Read recent activity and monitoring entries tail -n, /var/log/devserver/activity.log, /var/log/devserver/monitor.log

Commands are executed by the Flask backend with argument lists, not through a shell. The browser never runs host commands directly.

Add Developer Account

Regex: ^[a-z][a-z0-9_-]{1,31}$ (lowercase, starts with letter)
Default Policy: Account will be assigned to group developers with initial temporary password Welcome@123. The account is forced to set a new password on first login via chage -d 0.

Create Shared Git Repository

.git
Regex: ^[A-Za-z0-9._-]+$ (Letters, digits, dash, underscore, dot)
Security Architecture: Will run git init --bare --shared=group in /srv/repos/, set group ownership to developers, and configure setgid permissions (chmod 2775) so team pushes inherit permissions cleanly.

Delete Developer Account

Are you sure you want to permanently delete developer account username?

This command executes userdel -r <username>, removing their login credentials and home directory. System accounts (UID < 1000) are automatically protected.
